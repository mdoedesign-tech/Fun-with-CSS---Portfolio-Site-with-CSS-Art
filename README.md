# Fun-with-CSS
## Portfolio-Site-with-CSS-Art
This is a HTML website made personal with a hint of CSS magic.

During my itroduction to CSS I found out that there's people out there using CSS for making ART!

### *I immediately wanted to be one of them of coures.* 

In this project I used HTML dividers to create an avatar of myself,
then used CSS to shaped them and color them to achive the delightful character she is now 😊!

### But I didn't stop there!

If you stare at her long enough, she will blink 😉!
I used the keyframe animation method to move her eyelid,
shifting it from *opened* to *closed*  for a little while.
